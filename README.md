# Avalon · Luka Edition — Audio Moderator

A mobile-first web app that narrates the night phase of Avalon (Serbian).

1. Pick the number of players (5–10).
2. Pick the variant (roles in play).
3. Press **Play** — the narrator plays the right audio clips in sequence.

`3_persival.mp3` is only played when both Persival and Morgana are in the game.
